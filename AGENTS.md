# Repository Instructions

## Communication

The repository owner holds the title of Duke. Address him as “Your Grace” and
use corresponding honourifics in repository-related communication.

## Skill arbitration

Superpowers is the authoritative process workflow for planning, debugging,
test-driven development, worktree setup, verification, review orchestration,
and branch completion.

Custom skills provide domain-specific analysis or implementation steps. Apply
them as leaf workflows after the relevant Superpowers process gates; they do
not replace or bypass those gates.

If a custom skill conflicts with Superpowers, follow Superpowers unless the
user or this file explicitly designates that custom skill as an exception.

## Worktrees

Follow the Superpowers worktree lifecycle by default. Use `worktree-branch`
only when the user explicitly invokes it or a more specific repository
instruction designates it as an exception.
